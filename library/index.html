The quieter room for planning, research, source work, player material and archive work. It is separate from Control Room analytics.

Locked architecture

  • Staff-only through the existing Google / Firebase entrance.
  • Google Drive is the document/storage backend.
  • Only the SkyrScout Library root folder is fixed.
  • Child folders are discovered dynamically, not hard-coded into GitHub.
  • No Drive credentials or private tokens belong in the public site.
The room shell is live first. Drive browsing/search/write workflows come only after the roadmap below is approved.
